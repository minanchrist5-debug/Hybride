# SKILL — Production de Recommandations Stratégiques

## Quand utiliser ce skill
L'utilisateur mentionne : recommandation, reco, analyse, stratégie,
brief client, proposition, diagnostic, budget, campagne, rebranding,
positionnement, arbitrage, plan média, insight

## Contexte utilisateur
- Audience principale : clients agence (Advans, GIM-UEMOA, OBA, LDR Core...)
- Marché : Côte d'Ivoire + West Africa
- Format de livraison par défaut : PPTX (présentation client)
- Ton : professionnel, direct, orienté décision — jamais académique

---

## Détection automatique de la structure

### CAS 1 — Tu reçois un PROBLÈME FLOU ou une SITUATION À RÉSOUDRE
→ Utilise : Problème → Analyse → Recommandation

Structure des slides :
1. Le problème tel que le client le vit (1 slide)
2. Ce que les données révèlent réellement (1-2 slides)
3. La recommandation claire + justification (1 slide)
4. Plan d'action immédiat (1 slide)

### CAS 2 — Tu as des DONNÉES ou un BRIEF CLIENT
→ Utilise : Contexte → Insight → Action

Structure des slides :
1. Contexte marché / client (synthèse en 3 points max)
2. L'insight clé (ce que personne ne dit encore)
3. L'action recommandée + impact attendu
4. Métriques de succès

### CAS 3 — Le client doit CHOISIR entre plusieurs options
→ Utilise : Diagnostic → Options → Décision recommandée

Structure des slides :
1. Diagnostic de la situation actuelle
2. Option A / Option B / Option C (tableau comparatif)
3. Recommandation motivée (1 option claire, pas de "ça dépend")
4. Conditions de succès + risques

---

## Règles de production

### Toujours
- Commencer par lire toutes les infos disponibles avant de produire
- 1 idée = 1 slide (jamais plus de 5 bullet points par slide)
- Terminer par une slide "Next Steps" avec responsable + deadline
- La recommandation finale doit être tranchée — pas de formule molle

### Jamais
- Utiliser du jargon inutile ("synergies", "paradigme", "écosystème")
- Produire plus de 12 slides sans accord explicite
- Laisser le client sans option de décision claire

### Format PPTX
- Lire skills/generation-fichiers.md avant de générer le fichier
- Palette sobre : fond blanc ou sombre, 1 couleur d'accent max
- Slide de couverture : Nom client + Titre reco + Date
- Slide de fin : Logo agence + contact
